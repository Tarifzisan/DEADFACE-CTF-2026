# DEADFACE CTF 2026 — Writeups & Competition Journey

Welcome to my **DEADFACE CTF 2026** repository!

This repository documents my journey as a competitor in **DEADFACE CTF 2026**, featuring my challenge writeups, technical investigations, methodologies, and competition experience.

Throughout the competition, I explored various cybersecurity domains, solved challenges, and strengthened my practical skills through hands-on problem-solving.

## 🏴 About the Competition

**DEADFACE CTF 2026** is a Capture The Flag cybersecurity competition featuring challenges designed to test participants' technical knowledge, analytical thinking, and problem-solving abilities across different areas of cybersecurity.

As a competitor, I participated in multiple challenge categories and worked on investigating vulnerabilities, analyzing digital artifacts, extracting hidden information, and solving security-related problems.

## 📂 Repository Contents

This repository includes:

- **CTF Writeups:** Detailed explanations of solved challenges.
- **Digital Forensics:** Investigation and analysis of digital evidence.
- **OSINT:** Open-source intelligence gathering and analysis.
- **Web Security:** Web-based vulnerability investigation.
- **SQL & Database Forensics:** Database exploration and forensic analysis.
- **Mobile Security:** Static analysis of mobile application binaries.
- **Steganography & Cryptography:** Hidden data extraction and encoded information analysis.

Each writeup aims to explain the methodology, tools, commands, and thought process used to approach and solve the challenges.
